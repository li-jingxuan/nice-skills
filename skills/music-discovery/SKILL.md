# 查网易云音乐榜单

使用中文交互。从技能目录运行 `python3 scripts/music_discovery.py`。热门、新近热歌或热歌榜选 `hot`。升温、飙升或飙升榜选 `rising`。一次查一个榜，用户要求两个榜时分别查询并展示。默认取前 5 首，指定数量时传 `--limit`。

| 榜单 | 官方页面 | RSS 订阅 |
| --- | --- | --- |
| 热歌榜 | [网易云热歌榜](https://music.163.com/discover/toplist?id=3778678) | [热歌榜 RSS](https://rsshub.rssforever.com/163/music/playlist/3778678) |
| 飙升榜 | [网易云飙升榜](https://music.163.com/discover/toplist?id=19723756) | [飙升榜 RSS](https://rsshub.rssforever.com/163/music/playlist/19723756) |

1. 查询榜单时按官方顺序返回。回复时标出榜单名称和来源链接，使用命令输出到标准错误的官网更新日期（若有）。请求失败时说明来源暂时无法读取。用户明确要 RSS 内容时用 `--rss`。只需近期曲目且官方页读取失败时，也可尝试 `--rss`，并标明来自第三方订阅及顺序可能不同。需要精确排行时使用官方结果。飙升榜按当前榜单顺序展示，名次涨幅需要有对应历史数据才能给出。
2. 脚本在标准输出返回 UTF-8 JSON 曲目数组，包含 `title`、`artist` 和可用的 `album`，保留歌名里的版本后缀。歌手有多位时用 `/` 连接。用户要下载入参时，直接提供该数组或 UTF-8 清单文件。脚本返回非零状态或文件为空时，先报告取榜或写入失败，再决定是否重试。
3. 用户只要求查询、推荐、订阅或导出时，交付曲目或清单。明确要求下载时，把同一次查询的 JSON 保存到本机临时文件并交给已安装的 `music-download`。用 `batch-add --input <清单路径>` 建立批次，再依该技能的批量流程运行和查询状态。沿用用户指定的保存目录、格式和所选曲目。选了部分曲目时从已展示的数组中筛选，避免刷新榜单后换成别的歌。用户要求两个榜一起下载时，可按请求顺序合并两个数组交给同一个批次，由 `music-download` 处理查重和选源。

详细命令及清单示例见 [运行参考](references/runtime.md)。
